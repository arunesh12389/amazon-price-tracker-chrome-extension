# 🛍️ Amazon Price Tracker Chrome Extension

## Project Overview
The Amazon Price Tracker is a full-stack Chrome Extension built to empower users on **Amazon.in** with advanced, data-driven shopping intelligence. It goes beyond basic tracking, offering **AI-powered price forecasting**, interactive historical data, and **email alerts** to ensure users buy at the optimal time.

---

## Core Features

| Feature | Description | Technology Used |
| :--- | :--- | :--- |
| **📈 Price History Chart** | Injects an interactive chart (**Chart.js**) onto the Amazon product page, visualizing the entire scraped price history. | Chrome Extension, Chart.js, FastAPI |
| **🧠 AI Buy/Wait Advisor** | Provides a definitive recommendation ("**Buy Now**" or "**Wait**") based on **Prophet/Scikit-learn** time-series analysis and a summary generated by **LLaMA 3.3 70B-Versatile** (via Groq). | Groq API, Prophet/Scikit-learn (ML), FastAPI |
| **🔔 Price Drop Alerts** | Notifies the user via email (**Brevo API**) the moment the product's price drops below their set threshold. | APScheduler, Brevo API, MongoDB |
| **📝 Smart Product Summary** | Uses the LLM to convert verbose scraped product specs into a concise, human-friendly "**TL;DR**" or "**Smart Highlights**" section for quick decision-making. | Groq API (LLaMA 3.3 70B) |
| **🔄 Automated Scraping** | A scheduled job runs every few hours (**APScheduler**) to scrape all tracked products using **Playwright** , keeping the price data fresh. | APScheduler, Playwright |
| **👤 User Dashboard** | Shows a comprehensive list of all products the user is currently tracking, their current prices, target thresholds, and price trend predictions. | MongoDB, FastAPI Endpoints |

---

## Technical Stack

| Component | Technology | Role |
| :--- | :--- | :--- |
| **Backend API** | **FastAPI** (Python 3.12+) | High-performance, asynchronous REST API for all data handling and logic. |
| **Database** | **MongoDB Atlas** | Stores `products` (with `price_history` arrays), `users`, and `alerts`. |
| **Web Scraping** | **Playwright** | Handles browser automation for reliable data extraction from Amazon.in. |
| **AI/ML** | **Groq (LLaMA 3.3 70B-Versatile)** | Generates price forecasts, "Buy/Wait" advice, and product summaries. |
| **Scheduling** | **APScheduler** | Manages the background job for periodic price updates and alert checks. |
| **Email Service** | **Brevo** | Powers transactional email notifications for price drops. |
